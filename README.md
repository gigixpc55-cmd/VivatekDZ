# VivaTek DZ — site vitrine

Site vitrine responsive pour VivaTek DZ, avec une identité bleu nuit et or, une introduction en français/arabe et des liens vers Instagram, Facebook et TikTok.

## Tester le site
Ouvrez `index.html` dans votre navigateur. Une connexion Internet est nécessaire pour charger les polices Google; le reste du site est statique.

## Vérifier les liens avant publication
- Instagram : `https://www.instagram.com/vivatek_dz/`
- TikTok : `https://www.tiktok.com/@vivatek_dz`
- Facebook : le lien est actuellement générique. Dans `index.html`, remplacez les occurrences de `https://www.facebook.com/` par l'URL exacte de votre page VivaTek.Dz Shop.

## Publier gratuitement avec GitHub Pages
1. Connectez-vous à https://github.com/new
2. Créez un dépôt nommé `vivatek-dz` et sélectionnez **Public**.
3. Dans le dépôt, cliquez sur **Add file → Upload files**.
4. Téléversez `index.html`, `style.css`, `README.md` et le dossier `assets` (avec `favicon.svg`).
5. Cliquez sur **Commit changes**.
6. Ouvrez **Settings → Pages**.
7. Sous **Build and deployment**, choisissez **Deploy from a branch**.
8. Sélectionnez la branche `main`, le dossier `/ (root)`, puis cliquez sur **Save**.
9. Attendez quelques minutes. L'adresse du site apparaîtra dans la section Pages, généralement sous la forme `https://VOTRE-NOM.github.io/vivatek-dz/`.

## Modifier le site
- Textes et liens : `index.html`
- Couleurs, mise en page et responsive : `style.css`
- Icône du navigateur : `assets/favicon.svg`

Ce site est une vitrine statique : il ne collecte pas de données et ne nécessite ni base de données ni serveur.
